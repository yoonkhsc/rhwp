## 해석

- 5글자가 처음 들어가는 폭: **−20% → 4,100**, **+20% → 5,650**.
- 두 값은 "자간을 글자 **사이**에만 센다(줄 마지막 글자 뒤 자간은 제외)" 모델과 맞는다. 이것이 `line_breaking.rs` 의 기존 후보 끝 보정이다.
- 음수 자간 보정을 없애면(`.max(0)`) rhwp 는 −20% 에서 5글자를 3,900 HWPUNIT 로 재어 **3,950 셀에 5글자를 넣는다** — 한컴은 4,050 까지 4글자다. 따라서 `가나다라마` 기대값은 틀렸고 `가나다라` 가 맞다.
- 이 PR 이 실문서에서 봤던 개선(57.8% → 92.9%)은 그 문서의 본문 글꼴(바탕 13pt)이 측정 환경에 없어 대체 글꼴 advance 로 잰 오차를 보정 제거가 우연히 상쇄한 것이었다. 별개 과제로 남긴다.
